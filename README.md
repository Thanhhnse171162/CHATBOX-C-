# Chat Group — C# (chatting-group)

## Chạy

1. PostgreSQL — cấu hình `csharp/ChatServer/appsettings.json`
2. `CREATE DATABASE chatting_group;`
3. Server: `dotnet run --project csharp/ChatServer`
4. Client: `dotnet run --project csharp/ChatClient`
