# Chat Group — Desktop App

Ứng dụng chat nhóm chạy trên **máy tính** (cửa sổ PC), không cần mở trình duyệt.

## Chạy app

```bash
npm install
npm start
```

## Lưu ý

- `server.js` chạy **ngầm** bên trong app (phục vụ chat realtime), không cần mở http://localhost:3000 trên Chrome.
- Không dùng `npm run dev` / web — chỉ cần `npm start`.
